# 5. 受け入れ基準

原則:
- 解析的に正解が決まるものは**数値**で検証する（許容誤差を明記）。
- 絵全体は**参照画像比較**で検証する。参照は CPU リファレンスレンダラーの出力を目視確認のうえ固定したもの。
  GPU バックエンド（M3〜）も同じ参照と比較する。
- 参照画像比較の既定許容: 8bit sRGB で**最大差 2・RMSE 0.25 以下**。GPU バックエンドは最大差 3・RMSE 0.5 以下。
  不一致時は `*.actual.png` を出力する。更新は `ZND_BLESS=1 cargo test`（差分を目視してからコミット）。

### 性能（`znd bench`）

1080p・平面 200 枚（半透明・回転・キーフレーム・描画モード混在）で、1/2 解像度の複数フレーム並列レンダリングが
**30fps 以上**（実測 36fps、Apple Silicon 4+4 コア）。

### アプリ（手動確認）

M1 のアプリは自動 UI テストを持たない。`znd-app <プロジェクト> --frame N --screenshot out.png` で
起動〜描画〜スクリーンショット保存までを自動確認できる。編集操作の確認手順:

1. デモを開き、Space で再生。タイムラインに緑のキャッシュバーが伸び、再生が滑らかになる。
2. レイヤーを選び、位置をドラッグ → ビューアに反映。⌘Z で 1 回のドラッグが 1 手で戻る。
3. ⏱ でアニメーションを開始し、別フレームで値を変える → キーが 2 つでき、補間される。
4. 保存せずに終了して再起動 → 復旧ダイアログが出て、復元できる。
5. ファイル → H.264 で書き出す → 進捗表示、完了後に再生できる。
